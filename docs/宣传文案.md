## 标准文案（仓库 About / 产品页 / 邮件推荐，约 350 字）

**DSH Wiki 知识库（dsh-local-llm-wiki）—— 把散落的文档，炼成会回答的知识库**

产品手册、运维规程、项目归档……文档越攒越多，真正要用时却总在最深的文件夹里。DSH Wiki 知识库插件给 DeepSeek Harness 补上了「知识底座」这一环：

- **拖拽上传即可**：Web 面板把 PDF / Word / Markdown 拖进去，原始文件落 `raw/` 层永不改动，SHA256 清单记账，重复上传只重建变化的部分。
- **一键 AI 编译**：点「⚡ 一键构建」，插件发起一个真实 DSH 会话，按内置的 llm-wiki 技能完成 SCHEMA 设计 → 页面编译 → 收割入库，产出结构化的实体页、概念页、对比页；也可以分步执行，每一步留人工把关。
- **助手直接会答**：知识库以 `wiki_search` / `wiki_read` 等 5 个工具注册给助手——问领域问题时，它检索你自己的知识库，答案带着页面出处，不再靠模型猜。
- **质量看得见**：构建后自动 lint，断链、结构缺节、frontmatter 字段逐项报告，可一键交给会话修补；数据全部存在本地目录，不上传任何云端。

多项目独立成库，产品、运维、归档各管各的。MIT 开源，`dist/` 已入库，安装无需构建：profile 的 `dependencies` 填 `github:jazhu/dsh-local-llm-wiki#v0.4.7`，`pnpm install` 后重启 DSH，侧栏即见「📚 Wiki 知识库」。

**下载地址：https://github.com/jazhu/dsh-local-llm-wiki**

## 安装速查（附在文案末尾用）

1. 打开 DSH profile 的 `package.json`：
   ```json
   {
     "dependencies": { "dsh-local-llm-wiki": "github:jazhu/dsh-local-llm-wiki#v0.4.7" },
     "dsh.profile.bundles": ["dsh-local-llm-wiki"]
   }
   ```
2. profile 的 `cordis.patch.yml` 追加：
   ```yaml
   - insert:
       - id: dsh-local-llm-wiki
         name: dsh-local-llm-wiki
   ```
3. `pnpm install` 后**完整退出并重开 DSH** → 侧栏出现「📚 Wiki 知识库」。
